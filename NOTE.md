# Project Idea: Custom Sandwich Builder
For Project 1, I would like to create a program that allows a user to build custom sandwich by selecting different ingredients

Each ingredient would have a set price and weight. The idea is that the program would keep track of the ingredients selected by the user and calculate the total price and weight of the completed sandwich

The idea is similar to ordering a customized sandwich/bowl at a restaurant or frozen yogurt at a parlor, where the customer chooses the individual ingredients they want.

**How it would work**

The program could allow users to 

- Choose a type of bread
- Choose types of meats and cheeses
- Add toppings and other ingredients
- Choose how many servings or pieces of an ingredient thay want
- Calculate the total price of the sandwich
- Calculate the total weight of the sandwich
- Display the summary of the order

For example, if one slice of ham weighs 28 grams and costs $1.00, selecting two slices would add 56 grams and $2.00 to the order.

Each ingredient could have infomation;
- Ingredient name
- Price
- Weight
- Quantity selected

The program would use the information to calculate the final order and all that.
