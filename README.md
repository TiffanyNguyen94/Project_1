# Project 1 - custom sandwich builder

This repository contains my Project 1 for the Python programming course


## Project Overview

The program allows a user to create a sandwich by choosing different ingredients such as bread, meat, cheese, and toppings.

Each ingredient has its own price and weight, and the user can also choose quantities for certain ingredients. The program keeps track of everything selected and then calculates the final price and total weight of the sandwich.
